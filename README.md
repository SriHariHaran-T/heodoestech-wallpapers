# heodoestech-wallpapers

A collection of wallpapers for Linux desktops, ricing, and everyday use.

## Preview

Browse the repository to explore the available wallpapers.

## Source

Wallpapers in this collection have been gathered from sources including:

[Wallhaven](https://wallhaven.cc/)

[Wallhalla](https://wallhalla.com/)

[dharmx/walls](https://github.com/dharmx/walls)

Other websites and repositories that I may have forgotten.

## Usage

1. Browse the wallpapers in this repository.
2. Open the image you like.
3. Download it and set it as your desktop wallpaper.

On Linux, you can use `feh`:

```bash
feh --bg-fill /path/to/wallpaper.jpg
```
